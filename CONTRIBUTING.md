# Contributing

Contributions should improve the clarity, safety, portability, or verifiability of agent skills.

## Required Standard

A new skill should define:

- purpose
- use conditions
- non-use conditions
- required inputs
- context requirements
- allowed tools
- denied operations
- approval gates
- execution steps
- verification
- failure behavior
- stop conditions

## Design Preference

Prefer narrow capabilities over broad "do everything" skills.

A good skill should be independently testable and should expose as little authority as possible.
